Smart Travel Management System (STMS)
Module 1: Itinerary Planning and Booking   (STMS-3 to STMS-7)
Module 2: Companion Matching and Collaboration (STMS-8 to STMS-11)

Run:
  pip install -r requirements.txt
  python app.py            -> open http://127.0.0.1:5000
Tests (delete tests/test.db first if it exists):
  python -m unittest discover tests
